### 📖 Passo a passo do projeto

1. **Criar uma pasta para o projeto** — organize os arquivos em um diretório dedicado.
   _Exemplo usado no notebook:_ `C:\API_GITHUB\javascript\GITHUB`
2. **Abrir a pasta no Visual Studio Code** — selecione o diretório criado para começar a trabalhar nela.
3. **Criar o arquivo `index.html`** — arquivo principal do site.
4. **Gerar a estrutura básica do HTML** — digite `!` e pressione `Enter` (atalho do Emmet) para o VS Code montar automaticamente o boilerplate HTML5.
5. **Começar a construção do projeto** — iniciar a edição do conteúdo HTML.
6. **Instalar a extensão Live Server** — permite visualizar o site em tempo real, atualizando o navegador a cada alteração salva.
7. **Abrir o projeto com o Live Server** — o navegador abre automaticamente exibindo o `index.html`.
8. **Criar o arquivo `.css`** — para estilização do site (use `Ctrl + Click` sobre a pasta para criar um novo arquivo).
9. **Criar o arquivo `scripts.js`** — para adicionar interatividade com JavaScript (mesmo atalho `Ctrl + Click`).
10. **Selecionar "Create File"** — confirmar a criação dos arquivos gerados nas etapas anteriores.
